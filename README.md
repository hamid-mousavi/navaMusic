# سامانه جامع پخش، مدیریت و پایش هوشمند مداحی و ادعیه (navaMusic)

سامانه‌ای یکپارچه برای گردآوری، پالایش، برچسب‌گذاری و انتشار قطعات صوتی مذهبی، مداحی، مراثی و ادعیه متصل به فضای ابری ابر آروان (S3) و ربات ادمین تلگرام.

---

## 🌟 بخش‌های اصلی سامانه

1. **پلیر عمومی (Web):**
   - پخش روان آثار به همراه همگام‌سازی صوت با فرازهای ادعیه و اشعار.
   - حالت رانندگی (Car Mode) با دکمه‌های بزرگ لمسی.
   - دسته‌بندی بر اساس مناسبت‌ها، مداحان و ادعیه.

2. **پنل مدیریت (Admin Dashboard):**
   - صف بررسی کاندیدها پیش از انتشار (Staging & Queue).
   - پایش خودکار کانال‌های یوتیوب و تلگرام.
   - استخراج متادیتای هوشمند و اتصال به فضای ابری S3 ابر آروان.

3. **ربات تلگرام ادمین (grammY):**
   - مدیریت صف، تأیید/رد قطعات و انتشار مستقیم در کانال‌های رسمی با همگام‌سازی لحظه‌ای با پنل وب.

---

## 🏗 معماری فنی و پشته فناوری

- **فرانت‌اند:** React 19، Vite، Tailwind CSS، Lucide Icons، Motion
- **بک‌اند:** Node.js 22، Express، TypeScript (`tsx`)
- **داده و ذخیره‌سازی:** دیتابیس SQLite با Repository Pattern، فایل‌های موقت در `staging/`، فضای ابری ابر آروان (S3 Compatible Object Storage)
- **پردازش رسانه:** `yt-dlp` و `ffmpeg` جهت استخراج صوت ۳۲۰kbps و متادیتا
- **هوش مصنوعی:** Google Gemini API جهت پیشنهاد هوشمند نام اثر، مداح، مناسبت و دسته‌بندی

## 🚀 راه‌اندازی سریع (Quick Start)

### ۱. پیش‌نیازها
- Node.js نسخه ۲۲ یا بالاتر و npm
- ابزار `ffmpeg` (جهت تبدیل فایل‌های رسانه‌ای)
- دریافت باینری `yt-dlp` با اسکریپت `scripts/install-ytdlp.sh`

### ۲. نصب وابستگی‌ها
```bash
npm install
```

### ۳. نصب `yt-dlp`
```bash
chmod +x scripts/install-ytdlp.sh
./scripts/install-ytdlp.sh
```

### ۴. تنظیم متغیرهای محیطی
فایل `.env.example` را به `.env` کپی نموده و مقادیر مورد نیاز را تکمیل نمایید:
```bash
cp .env.example .env
```

### ۵. اجرای سرور توسعه
```bash
npm run dev
```
برنامه روی آدرس `http://localhost:3000` در دسترس خواهد بود.

### ۶. بیلد برای محیط تولید
```bash
npm run build
npm start
```
